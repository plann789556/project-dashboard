# Dashboard V2 รายงานสถานะแผนงาน/โครงการ ปีงบประมาณ 2569

Web Dashboard แบบ static สำหรับ GitHub Pages พัฒนาต่อจาก V1 โดยเพิ่ม:

- เลือกปีงบประมาณและเดือนรายงาน
- KPI เปรียบเทียบแผนสะสมเฉลี่ยกับผลสะสมเฉลี่ย
- Traffic-light status: ปกติ / เฝ้าระวัง / ล่าช้า
- กดแต่ละโครงการเพื่อดูความก้าวหน้ารายเดือน แผน ผล และส่วนต่าง

## เกณฑ์สถานะ

- ปกติ (เขียว): ผล >= แผน - 5 จุดร้อยละ
- เฝ้าระวัง (ทอง): ผลต่ำกว่าแผนมากกว่า 5 ถึง 15 จุดร้อยละ
- ล่าช้า (แดง): ผลต่ำกว่าแผนมากกว่า 15 จุดร้อยละ

## หมายเหตุเรื่อง “แผน”

ไฟล์ต้นทางมีเฉพาะผลความก้าวหน้ารายเดือน ยังไม่มีค่าความก้าวหน้าตามแผนรายโครงการ ดังนั้น V2 ใช้เป้าหมายสะสมมาตรฐาน 100% ภายในเดือนกันยายน (ประมาณ 8.33% ต่อเดือน) เป็นค่าเริ่มต้น

เมื่อมีข้อมูลแผนจริง สามารถเพิ่ม `plan:[...]` ในแต่ละโครงการใน `data.js` ได้ ระบบจะใช้แผนรายโครงการแทน `standardPlan` โดยอัตโนมัติ

## อัปเดตบน GitHub

อัปโหลดไฟล์ `index.html`, `style.css`, `script.js`, `data.js` และ `README.md` ไปแทนไฟล์เดิมใน repository `project-dashboard` แล้ว Commit changes หลังจากนั้น GitHub Pages จะ Deploy เวอร์ชันใหม่อัตโนมัติ
