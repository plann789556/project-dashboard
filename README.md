## จุดแก้ไข
- แก้ปัญหาหน้า Dashboard แสดงเฉพาะโครงแต่ไม่มี KPI/กราฟ/รายการโครงการ
- ใช้ `window.DASHBOARD_DATA` เพื่อให้ `data.js` เชื่อมกับ `script.js` ได้แน่นอน
- ตัด dependency จาก Chart.js/CDN และวาดกราฟด้วย SVG/CSS จึงใช้งานบน GitHub Pages ได้โดยไม่พึ่งไลบรารีภายนอก
- แสดงข้อมูลครบ 9 โครงการ
- กราฟวงกลม: น้ำเงิน = แล้วเสร็จ, แดง = อยู่ระหว่างดำเนินการ
- แสดงเฉพาะผลความก้าวหน้าจริง ไม่ใช้แผนสมมติ

## การอัปเดต GitHub Pages
อัปโหลด `index.html`, `style.css`, `script.js`, `data.js`, `README.md` ทับไฟล์เดิมใน repository แล้ว Commit Changes จากนั้นรอ Deploy และกด Ctrl+F5 ที่หน้าเว็บไซต์
