# Project Dashboard V2.1 — Executive Navy

## Theme
- กรมท่า: Header / หัวข้อหลัก
- ฟ้า: KPI / กราฟผลการดำเนินงาน
- ทอง: Accent / แผน / เฝ้าระวัง
- ขาว: Card / พื้นที่ข้อมูล
- กราฟวงกลม: น้ำเงิน = ปกติ, ทอง = เฝ้าระวัง, แดง = ล่าช้า
